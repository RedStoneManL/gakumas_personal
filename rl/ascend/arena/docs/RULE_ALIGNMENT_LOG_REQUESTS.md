# HIF规则对齐后的实机日志采样清单

**最新优先级调整（2026-09-08）**：道具触发排序先用 [确定性默认](ARENA_TRIGGER_ORDER_UPDATE.md)，U02/U03/U07及除外／使用后次序的精细校准暂缓，不要求专门穷举或追加排列实验。其他机制可按现有编成顺手采样；以下方案保留供以后使用，不作为当前HIF完成前置条件。

**2026-09-08 操作版已补齐：[HIF真实卡牌组合与逐步采样](RULE_ALIGNMENT_REAL_CARD_RECIPES.md)。** 优先用用户现有【The Rolling Riceball】佑芽测计数，再做蛋白饮料跨回合、精神統一＋/ハイタッチ舍入；无需另外练R佑芽。指定偶像、支援卡事件、强化等级、有效初始状态和不能直接取得的组合都在操作版说明；下表保留问题索引，不要求在游戏里制造抽象的合成数值。**按用户最新范围，仅采HIF；パニック和偶像之路专属机制暂缓，不安排跨计划混合资源实验。**

2026-09-08。由用户或原游戏adapter session采样；Arena session不操作游戏。下面列的是剩余歧义，已实现部分见 [行为契约](ENGINE_RULE_CONTRACT.md)。一次只改变一个因素；不需要为每条都完成一整局。

已收到的实机结果：[饭团＋及6段相邻截图](research/riceball_photo_review_2026-09-08.md)。用户确认饭团是首张实际用卡，元气0→2支持Q09在该普通手动卡上的“不计当前卡”。同批新增“除外触发/使用后”差异已登记。可以接收其他模式的可隔离共用机制样本，不要求为了采样一定重新开HIF。

每段请保留：游戏版本、模式／剧本、回合属性、完整卡面及强化／自定义、P道具排列、前后资源、状态详情中的剩余回合／次数，以及从准备动作前到所有连锁结束的连续日志。若同时记录截图，附原始顺序，不能只给最终总分。adapter继续保留原command_id和卡实例身份；用户手记可以用“原卡A／复制卡B”区分。

| 优先级／问题 | 怎样制造可区分的情况 | 需要看哪一个差异 |
|---|---|---|
| P0 U01 集中混合舍入 | 低集中、集中强化、集中倍数参照卡组合，选择会产生小数的数值 | 是合并后取整，还是各参照部分分别取整。合成判别向量：基础6、集中1、强化20%、集中3倍，候选结果可为10／11；不要求游戏里刚好有这个卡面 |
| 暂缓 U03 状态费用与使用后 | 卡用强化状态支付费用；让费用触发先改变某资源，而另一个“使用后”触发以该资源为门槛 | 两个触发是否同批判资格，还是先费用触发再判使用后 |
| P0 Q10 行动数新旧混合 | 对比①开始时给追加次数后立即skip；②行动中获得追加次数后skip；③旧追加次数未耗尽时再获新次数；④旧次数耗尽后重新获得 | 记录每次用卡后、skip前、下一回合开始后的次数，判断消费顺序和寿命是否合并 |
| 暂缓 U02 每N回合资格 | 在第N回合，让开始时／记忆／预约中的较早效果把某个门槛从不满足变成满足 | 每N回合道具是否在该回合立即发动，定位资格快照时点 |
| P1 U04 付费自动使用不足 | 确认可支付后安排付费自动卡，随后同组效果使其费用不足；与足够费用作对照 | 是否取消、是否扣部分费用、是否计入使用次数、再演次数是否消耗 |
| 暂缓 U07 多张准备卡排序 | 同一组触发产生两个准备使用的卡，让先后顺序会改变分数或条件。交换道具显示顺序再对照 | 队列是FIFO、来源优先，还是新插入任务优先；原卡的后续行是否先完成 |
| P1 U06 延迟来源 | 同样+1好印象，分别用卡／饮料普通预约、持续附魔、附魔建立的预约触发；配“直接效果增加后”道具 | 哪些来源会触发道具，记录预约创建者和触发者 |
| P1 U08 获取固定值与百分比 | 同时存在固定追加和百分比获取增加，用小基数获取一次集中／好印象 | 如原值2、固定+1、百分比+50%，区分先加固定再乘与先乘后加，以及舍入位置 |
| P1 Q09 当前卡计数 | 使用“本场每用一张卡，参数增加量增加”的卡，记录此前完整使用次数，并与自动使用／追加发动分别对照 | 当前这张卡是否计入数值参照，自动卡与正文追加发动是否分别增加 |
| P2 Q12 解除种类与续加 | 先施加A再施加B，再续加A，使用“解除1种”；另测两种不同卡使用限制 | 最新“种类”指首次授予还是续加时点；使用限制是否分种类 |

全力阶段也建议留一段对拍：上回合末全力值达标 → 回合切换 → 正常抽牌 → 保留回收；另做本回合开始效果才达标的对照。若抽牌接近手牌上限，这段更容易区分回收位置与溢出处理。

暂缓项：U05パニック／偶像之路特有机制；Q11需要跨计划人为凑出的自然好印象组合；U02/U03/U07等细粒度排序。继续保留在行为契约中作为已知边界，但不作为当前HIF验收或联调的阻塞项。U04只在已有编成可顺手复现时采样，未覆盖部分不冒充已确认。

已确认案例的回归也可顺手采样：同批条件2→3、再演耗尽后的同卡再次使用、体力回复无效时skip、普通元气与固定元气。它们的引擎合成结果现已按报告对齐；采样用于提升证据等级。

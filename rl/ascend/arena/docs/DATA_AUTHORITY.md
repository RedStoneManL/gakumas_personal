2026-09-10，按用户最新决定生效：**主要事实数据使用 `vertesan/gakumasu-diff` 的解包主数据；与其他参考冲突时，以主数据为准。OCR 部分不纳入参考或接入。**

## 数据与执行的职责

- 卡片数值、费用类型和数额、绿豆价格与成长效果、支援技能档位、触发条件、事件选项、P 道具、奖励和剧本配置等，使用固定版本主数据的明确字段。`ExamSetting` 等表给出的算法常量也属于事实数据。
- `gakumas-tools` 保留为可复用的局内执行核心和算法参考。其手写目录或效果表达式与主数据明确字段冲突时，修正 Arena 的有效数据／执行适配，不保留错误值来追求上游输出一致。
- 主数据没有完整表达的取整、结算顺序、算法或概率分布，继续使用已接受的引擎语义／研究模型，并记录来源和假设。表中存在数值并不意味着全部客户端算法都已知。
- 实机截图作为补充证据和复现样本。修正明确的主数据冲突不再以补充实机验证为前置条件；若只是字段含义尚不明确，则记录语义问题，不把猜测标成主数据事实。

此规则覆盖此前“局内一律 golden 优先”的临时取舍，适用于后续发现的事实冲突，不仅限于已经修正的三张卡。

## RL 怎样使用

- JSON 的 `samples` 含两条独立观察，用 `exam_round` 区分场次。`score_percents` 可直接传给 Arena 同名参数；例如第二轮为 `[4208,2886,2128]`。这些已经包含最终加成，**不要再乘スター性或开场加成**。
- 原始三维、star 和本轮基准作为倍率建模的观察条件保留。这两点尚不能确定完整换算曲线；亲爱度分数效果、精确 P 偶像／审查配置 ID 未提供。数据里没有完整卡组，其他入场条件需沿用该场实际配置。
- 阶段 A/B 是界面显示整数。第一轮 `1466×3=4398`，菜单却是 `4397%`，因此不能逐层拿显示整数当内部精确值。界面共同标记 950 也未确证为三维各自门槛。
- 两组同时改变了场次、star 基准和 Da；不能直接用最终倍率差值计算单次 Da 或 star 加点收益。它们也不与旧的 508647 分第一轮日志合并。

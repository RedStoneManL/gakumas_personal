## 可配置范围

| 元件 | 当前支持 |
|---|---|
| 培养类型/偶像 | sense、logic、anomaly；原生154偶像或显式无偶像 |
| 牌组 | 原生870定义，0..512入场副本，定制/成长/独立身份；运行中最多4096实例 |
| 道具/饮料 | 原生484道具、28饮料；显式配置，不强制固定装备 |
| HIF模板 | 广140的可编辑12回合起始模板，所有字段可覆盖 |
| 计分 | 原生percent输入，或golden_contest_params属性计算；HIF模板用最终百分比，无额外校准profile |
| 回合 | 原生计数/首回合概率/criteria生成，或1..300回合显式序列 |
| 补牌 | 实际应援棒的原生规则和显式基础池，不在RL层补22；保留golden采样 |
| 附加效果 | 原生舞台DSL、逐副本bindings、全局memory_abilities、persistent_effects；独立counter和剩余limit |
| 入场边界 | before_opening；当前局恢复用snapshot，不能把已开局状态重复初始化 |

配置自由不等于声称任何牌表都自然培育可达。无需证明自然可达即可构造训练课程；ID、字段、唯一性和原生操作仍验证。单偶像contest/event已接，多偶像linkContest未接。

用户508,647分图片明确是HIF本战Round1，可作历史资料；当前golden验收不要求重现该实机分数，也不将其当Round2预期。

## 剩余事项分类

- **自定义golden单偶像考试纯策略训练：**本轮接口与已验收组合无剩余阻塞；可开始接训练。新课程记录有效配置，先跑一次完整rollout检查组合执行。
- **公开历史搜索：**S02 新接口已提供；有限粒子及预算仍需逐根准入，不能用原局 fork 替代失败根。生产 collector/模型/优化器迁移是 RL 侧待办。
- **培育加点评估：**采用用户研究包近似公式；独立换算与 golden 接入测试见 HIF_SCORING_MODEL.md，不将经验模型标为客户端精确实现。
- **规模效率：**长journal重放、并发内存、平台和编码成本需实测。
- **后续范围：**多偶像linkContest、官方完整培育随机分布/精确奖励池抽样、倍率未识别分支、Python 同步回调栈中的任意选择点全局恢复；HIF 外出、可配置中场/两轮、研究包近似换算及已支持内容的跨场映射已经接入。
- **实机对拍：**用户已明确不作为本轮验收要求，不阻塞上述GO。

# HIF 五场考试倍率研究包 — 给本地 agent

研究截止：2026-09-09。模型：hif-display-v0.3-empirical-2026-09-09。

## 阅读顺序

1. 先读本文件，确认适用范围。
2. 读 HIF_考试倍率公式核对_2026-09-09.md：完整研究报告，含公式、取整、五场基准、六种属性曲线族、全部原始节点、来源链接及局限。
3. 读 hif_multiplier_research_2026-09-09.json：可机读主数据、14 组样本、判定信息、原图 URL、假设和证据标记。
4. 参考 hif_multiplier_model.py：Python 标准库实现，含实测复算和显式开启的实验分支。
5. sample_template.json 用于新增实机记录；audit.json 是当前样本复算结果。

## 必须保留的研究边界

- 全部数组按 Vo / Da / Vi（红 / 蓝 / 黄）排列。
- 审查主 / 次 / 第三属性由 P 偶像的考试配置决定，不按当前属性大小重新排序；区分均衡型与突出型。
- 无三维短板惩罚时，当前候选为 A=ceil(100+L/10)，B内部=A×亲爱度因子，最终显示=ceil(B内部×スター性因子)。L 是主数据节点的线性插值。
- 本批亲爱度因子取 1.5。B 的显示取整值不能直接回填计算，例如 1466 的内部值可能为 1465.5。
- 本战スター性分母 270 / 325 是经验候选；前三场未封顶曲线和低于スター性基准的区间尚未识别。实验插值不可标为已验证公式。
- ◎ / ○ / △ / × 是独立输入。△ / × 会涉及跨颜色惩罚，但惩罚幅度、门槛、组合方式和所在层尚未用 HIF 完整记录校准。
- settings-prior 是全局 100 / 250‰ 设置与旧模式线索构成的实验假说，不是 HIF 客户端定论。不要把实验模式设成无提示默认值。
- 14 组中 13 组三色全相符、41 / 42 个最终百分数相符；这是同一批资料的重建，不是独立测试集准确率。
- SM-R2 的 Vi 异常必须保留。原始 1572 / 2681% 不能为了符合公式而修改。
- 用户两组数据来自会话汇总表；原始照片及用户所提相对路径 JSON 的文件字节未取得。网上样本原图在报告与 JSON 中提供链接，未打包网页图片。
- 这里解释的是界面倍率，不是单张卡牌实际得分的最终舍入规则。

## 最小运行

解压后，在本目录使用 Python 3；不需要安装第三方依赖。

审计全部样本：

    python hif_multiplier_model.py --audit

复算用户本战 R2（明确按无短板惩罚处理）：

    python hif_multiplier_model.py --family voda-03 --stage round2 --stats 2759 1744 1209 --star 1083 --all-qualified

预期 score_percents 为 [4208, 2886, 2128]。

实验性未达标试算与替代模型的参数见完整报告第 8 节，或运行：

    python hif_multiplier_model.py --help
